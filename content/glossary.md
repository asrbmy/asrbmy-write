---
title: Glossary
---

## Markdown
A plain-text way of writing headings, lists and links with simple symbols, so a file stays readable anywhere and can be turned into a web page.

## RSS | feed
A standard format that lets a reader app collect new articles from many sites in one place, without accounts or email.

## Git
A tool that records every change to a set of files, so you can go back to any earlier version and work with other people without overwriting each other.

## Repository | repo
A project folder tracked by Git, usually hosted on a service such as GitHub.

## Threat model
A short, honest list of what you are protecting, who might want it, and what you are willing to do about it.

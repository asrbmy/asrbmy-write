## Why this site exists

{{name}} is where I put things I have learned so I can find them again, and so others can too. It is independent and personal: no ads, no sponsors, no tracking scripts.

- **Privacy** — practical notes on staying private online.
- **Personal** — essays on learning and writing.

## How it is built

This is a static site generated from Markdown files and hosted on GitHub Pages. Every article lives in a plain text file, so the writing stays portable and the site stays fast. You can follow new posts through the [RSS feed](/rss.xml), browse the [archive](/archive/), or [search](/search/) everything.

ASRBMY Write turns plain Markdown files into a fast, searchable website. There is no database and no login: you write on your own computer, upload the files, and GitHub Pages does the rest.

## Why it exists

Most blogging tools want an account, a server or a subscription. This one wants a folder of text files.
